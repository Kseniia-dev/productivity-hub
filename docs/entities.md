# Entities

## User

### Что это такое

User — зарегистрированный пользователь приложения.

### Зачем нужна

Нужна, чтобы сохранять задачи, фокус-сессии, личный кабинет, статистику и роль пользователя.

### Обязательные поля

- id
- email
- password_hash
- role
- created_at

### Необязательные поля

- username
- updated_at

### Роли / статусы

Роли:
- user
- admin

Guest не хранится в базе данных как полноценный пользователь. Guest — это режим использования приложения без сохранения данных на backend.

### Связи

- один User может иметь много Task
- один User может иметь много FocusSession

### Правила

- email должен быть уникальным
- email должен быть валидным
- password_hash хранит не пароль, а его хэш
- обычный пользователь не может менять свою роль
- роль может менять только admin

## Task

### Что это такое

Task — задача пользователя на конкретную дату.

### Зачем нужна

Нужна, чтобы пользователь мог планировать день, видеть список дел и отмечать выполнение.

### Обязательные поля

- id
- user_id
- title
- date
- status
- created_at

### Необязательные поля

- description
- start_time
- estimated_minutes
- updated_at

### Статусы

- planned
- in_progress
- done
- undone
- cancelled

### Связи

- одна Task принадлежит одному User
- одна Task может иметь несколько FocusSession

### Правила

- title не должен быть пустым
- date обязательна
- если estimated_minutes указана, она должна быть больше нуля
- пользователь может видеть только свои задачи
- пользователь может создать несколько задач на одно и то же время
- одновременно нельзя запускать несколько задач в фокусе
- при удалении задача удаляется полностью

## FocusSession

### Что это такое

FocusSession — период фокусировки пользователя.

### Зачем нужна

Нужна, чтобы пользователь мог работать по циклам фокусировки и отдыха, а приложение могло сохранять активные и завершённые сессии.

### Обязательные поля

- id
- user_id
- focus_minutes — длительность одного фокус-периода
- break_minutes
- total_focus_minutes — общее запланированное время фокусировки.
- status
- started_at
- created_at


### Необязательные поля

- task_id
- ended_at
- completed_cycles
- updated_at
- planned_cycles

### Состояния

- running
- paused
- completed
- cancelled

### Связи

- одна FocusSession принадлежит одному User
- одна FocusSession может быть связана с одной Task
- одна Task может иметь несколько FocusSession

### Правила

- focus_minutes должен быть больше нуля
- break_minutes должен быть больше или равен нулю
- total_focus_minutes должен быть больше нуля
- одновременно у пользователя может быть только одна активная FocusSession
- если пользователь обновляет страницу, активная FocusSession восстанавливается
- время в фокусе считается без учёта перерывов
- после завершения сессии приложение предлагает отметить задачу как done, если сессия была связана с задачей
- total_focus_minutes считается без учёта перерывов

## Общие правила

- Все даты и время хранятся в едином формате.
- Пользовательские данные не должны быть доступны другим пользователям без разрешения.
- Guest-данные не сохраняются на backend.
- MVP не включает будущие сущности из списка ниже.

## Будущие сущности

- Note — заметка пользователя, связанная или не связанная с задачей.
- ImportantDate — важная дата в отдельном календаре.
- CycleCalendar — календарь отслеживания женского цикла.
- DiaryEntry — приватная запись личного дневника.
- SharedAccess — доступ, который пользователь выдаёт другому человеку.
