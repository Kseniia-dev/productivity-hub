# MVP

## Главная цель MVP

MVP должен помочь пользователю спланировать задачи на день, запустить фокус-сессию для работы или учёбы, сохранить прогресс и увидеть простую статистику по выполненным задачам.

## Для кого MVP

MVP предназначен для:
- удалёнщиков;
- фрилансеров;
- студентов.

Эти пользователи работают или учатся самостоятельно и хотят лучше организовывать своё время без сложных систем планирования.

## Основной пользовательский сценарий

1. Пользователь открывает приложение.
2. Пользователь регистрируется или входит в аккаунт.
3. Пользователь попадает на главную страницу с календарём.
4. Пользователь выбирает дату.
5. Пользователь создаёт задачи на день.
6. Пользователь запускает фокус-сессию для задачи или без задачи.
7. Пользователь работает по выбранному времени фокуса и перерывов.
8. После завершения фокус-сессии приложение предлагает отметить задачу как выполненную.
9. Пользователь видит простую статистику по задачам текущего дня в личном кабинете.
10. Гостевые данные хранятся только на frontend и не попадают в backend;

## Входит в MVP

### Auth

- регистрация через email и password;
- вход через email и password;
- выход из аккаунта;
- режим гостя без сохранения данных на backend;
- сообщение об ошибке при неверном пароле.
- пользователь может выйти из аккаунта;

### Users

- личный кабинет пользователя;
- просмотр username, email и роли;
- изменение username;
- изменение пароля;
- простая статистика за текущий день;
- роли guest, user, admin.

### Tasks

- создание задачи на выбранную дату;
- просмотр задач за выбранную дату;
- редактирование задачи;
- изменение статуса задачи;
- удаление задачи;
- статусы planned, in_progress, done, undone, cancelled;
- необязательные поля: описание, время начала, длительность.

### Focus Sessions

- запуск фокус-сессии без задачи;
- запуск фокус-сессии для конкретной задачи;
- настройка времени фокуса;
- настройка времени перерыва;
- настройка общего времени фокуса или количества циклов;
- пауза;
- продолжение;
- завершение;
- отмена;
- восстановление активной сессии после обновления страницы;
- история фокус-сессий за день;
- предложение отметить задачу как done после завершения сессии.

### Admin

- отдельная admin-страница;
- просмотр количества зарегистрированных пользователей;
- просмотр общего количества задач;
- просмотр количества завершённых задач;
- просмотр количества фокус-сессий;
- изменение ролей пользователей.
- admin может видеть общую статистику приложения;

## Не входит в MVP

- восстановление пароля;
- смена email;
- загрузка фото профиля;
- публичные профили пользователей;
- просмотр статистики других пользователей;
- перенос задачи на другой день до 3 раз;
- блокировка пользователей;
- просмотр админом задач всех пользователей;
- заметки;
- отдельный календарь важных дат;
- женский календарь;
- шеринг цикла с партнёром или партнёршей;
- личный дневник;
- desktop-приложение;
- push-уведомления;
- синхронизация с Google Calendar или другими календарями;
- сложная аналитика.

## Критерии готовности MVP

MVP считается готовым, если:

- пользователь может зарегистрироваться и войти;
- пользователь может создать задачу на выбранную дату;
- пользователь может увидеть задачи выбранного дня;
- пользователь может изменить статус задачи;
- пользователь может удалить задачу;
- пользователь может запустить фокус-сессию для задачи;
- пользователь может запустить фокус-сессию без задачи;
- пользователь может поставить фокус-сессию на паузу и продолжить её;
- активная фокус-сессия восстанавливается после обновления страницы;
- завершённая фокус-сессия сохраняется в истории за день;
- после завершения фокуса пользователь может отметить задачу как done;
- пользователь видит простую статистику в личном кабинете;
- admin может открыть admin-страницу и изменить роль пользователя;
- guest может пользоваться приложением без сохранения данных на backend;
- пользователь не может видеть чужие задачи;
- обычный пользователь не может открыть admin-страницу.

## Будет после MVP

После MVP планируется добавить:

- восстановление пароля через email;
- смену email с подтверждением;
- загрузку фото профиля;
- публичные профили пользователей;
- статистику других пользователей;
- перенос задач на другие дни с ограничением до 3 раз;
- блокировку пользователей администратором;
- расширенную admin-панель;
- заметки;
- календарь важных дат;
- женский календарь;
- возможность шерить цикл с партнёром или партнёршей;
- секретные страницы или личный дневник;
- desktop-версию приложения;
- уведомления;
- интеграции с внешними календарями;
- расширенную аналитику продуктивности.
