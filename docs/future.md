## Цель файла

Этот файл нужен, чтобы сохранять идеи для будущих версий ProductivityHub, не добавляя их в MVP раньше времени.

Если идея попала в этот файл, значит она важна, но не входит в первую версию продукта.


## После MVP

- восстановление пароля через email;
- смена email с подтверждением;
- загрузка фото профиля;
- публичные профили пользователей;
- статистика других пользователей;
- перенос задач на другие дни с ограничением до 3 раз;
- блокировка пользователей администратором;
- расширенная admin-панель;
- заметки;
- календарь важных дат;
- женский календарь;
- шеринг цикла с партнёром или партнёршей;
- личный дневник;
- desktop-версия приложения;
- уведомления;
- интеграции с внешними календарями;
- расширенная аналитика продуктивности.


## Идеи для личной продуктивности

- шаблоны дня;
- повторяющиеся задачи;
- приоритеты задач;
- категории задач;
- теги;
- цели на неделю;
- цели на месяц;
- режим “мягкого планирования” без точного времени;
- режим “жёсткого расписания” с точным временем;
- рекомендации по перерывам;
- история продуктивных дней.


## Идеи для календарей

- отдельный календарь важных дат;
- недельный вид;
- месячный вид;
- перенос задач drag-and-drop;
- цветовые категории задач;
- дедлайны;
- повторяющиеся события;
- синхронизация с Google Calendar;
- синхронизация с Outlook Calendar.


## Идеи для приватности и личных данных

- личный дневник;
- секретные страницы;
- PIN-код или дополнительная защита для дневника;
- шифрование приватных записей;
- настройка видимости личных данных;
- экспорт личных данных;
- удаление аккаунта и всех данных;
- отдельные настройки приватности для женского календаря.


## Идеи для социальных функций

- публичные профили пользователей;
- просмотр базовой статистики других пользователей;
- возможность делиться прогрессом;
- шеринг женского календаря с партнёром или партнёршей;
- управление доступом к расшаренным данным;
- приглашения по email;
- список доверенных пользователей.


## Идеи для desktop-версии

- desktop-приложение на Tauri или Electron;
- локальные уведомления;
- работа без интернета;
- автозапуск фокус-режима;
- мини-виджет таймера;
- системный tray-значок;
- быстрый старт фокуса из desktop-приложения.


## Идеи для аналитики

- статистика выполненных задач за неделю;
- статистика выполненных задач за месяц;
- процент завершения задач;
- общее время в фокусе;
- средняя длительность фокус-сессии;
- лучшие дни недели по продуктивности;
- сравнение планируемого и фактического времени;
- графики продуктивности;
- streak-дни.


## Не решено

- Нужно ли делать мобильную версию отдельно или достаточно адаптивного сайта?
- Нужно ли хранить guest-задачи в localStorage или только в памяти вкладки?
- Как именно должна работать логика “выполнено вовремя”?
- Нужно ли пользователю вручную задавать рабочие часы?
- Нужно ли добавлять темы оформления?
- Как будет устроена desktop-версия: Tauri или Electron?
