# ProductivityHub

## Описание

ProductivityHub — веб-приложение для планирования задач на день, запуска фокус-сессий и отслеживания простого прогресса.

Проект создаётся как учебный fullstack-проект, чтобы постепенно пройти путь от идеи и документации до frontend, backend, базы данных, авторизации, ролей и будущей desktop-версии.

## Для кого

Проект предназначен для людей, которые работают или учатся самостоятельно:

- удалёнщиков;
- фрилансеров;
- студентов;
- людей, которые хотят лучше организовывать свой день.

## Главная идея

ProductivityHub помогает пользователю превратить хаотичный день в понятный рабочий ритм:

1. выбрать дату;
2. создать задачи на день;
3. запустить фокус-сессию;
4. сделать перерыв;
5. сохранить прогресс;
6. увидеть простой результат дня.

## MVP

В первую версию входит:

- регистрация и вход через email и password;
- режим гостя без сохранения данных на backend;
- личный кабинет пользователя;
- роли guest, user, admin;
- задачи на выбранную дату;
- создание, редактирование, удаление и изменение статуса задач;
- фокус-сессии для задачи или без задачи;
- пауза, продолжение, завершение и отмена фокус-сессии;
- восстановление активной фокус-сессии после обновления страницы;
- простая статистика за день;
- admin-страница с общей статистикой и управлением ролями.

## Не входит в MVP

- восстановление пароля;
- смена email;
- загрузка фото профиля;
- публичные профили;
- заметки;
- календарь важных дат;
- женский календарь;
- личный дневник;
- desktop-приложение;
- уведомления;
- интеграции с внешними календарями;
- расширенная аналитика.

## Документация

Основные документы проекта находятся в папке `docs/`:

- `idea.md` — идея проекта и основная ценность;
- `mvp.md` — границы первой версии;
- `api.md` — черновик API;
- `entities.md` — основные сущности проекта;
- `decisions.md` — журнал технических решений;
- `future.md` — идеи для будущих версий.

## Как запустить проект

Инструкции по запуску будут добавлены после настройки frontend, backend и базы данных.

## Статус проекта

Проект находится на этапе подготовки документации и структуры.

Текущий этап:

- описана идея проекта;
- определены границы MVP;
- описан черновик API;
- описаны основные сущности;
- зафиксированы первые технические решения;
- собран список будущих возможностей.
